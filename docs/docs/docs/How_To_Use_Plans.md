# Как использовать планы

## Ежедневный ритуал (утром, 2–3 минуты)

1. Зайди на GitHub → репозиторий `My_Dev_Career` → папка `docs`.
2. Открой `General_Plan.md` – пробегись взглядом по этапам, убедись, что ты на правильном пути. Закрой.
3. Открой `Executive_Plan_September_2024.md` – найди сегодняшнюю дату, прочитай задачу. Если всё совпадает – закрывай.
4. Если нужно что-то изменить – нажми карандашик (✏️) в файле, внеси правки, внизу напиши комментарий и нажми **«Commit changes»**.
5. Закрой GitHub и начинай учиться по плану.

---

## Еженедельный ритуал (в воскресенье вечером, 5–10 минут)

1. Открой `Executive_Plan_September_2024.md`.
2. Просмотри прошедшую неделю: что сделано, что нет.
3. Напиши мне (в этот чат) краткий отчёт:
   - *«Сделал: ...»*
   - *«Не сделал: ...»*
   - *«Трудности: ...»*
4. Я помогу скорректировать план на следующую неделю.
5. После обсуждения внеси правки в файл и сделай коммит.

---

## Ежемесячный ритуал (в последнее воскресенье месяца, 15–20 минут)

1. Открой текущий исполнительный план (например, `Executive_Plan_September_2024.md`).
2. Проанализируй весь месяц: что удалось, что нет.
3. Напиши мне отчёт за месяц.
4. Вместе со мной создай новый файл для следующего месяца (например, `Executive_Plan_October_2024.md`).
5. Если нужно – обнови `General_Plan.md` и сделай коммит.

---

## Правила

- Ничего лишнего. Планы – это инструмент, а не самоцель.
- Если отстаёшь – не паникуй, корректируй план.
- Если опережаешь – добавляй дополнительные задачи.
- Все изменения фиксируй коммитами с понятными сообщениями.
