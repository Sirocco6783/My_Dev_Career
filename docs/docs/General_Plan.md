## Правила корректировки

### Когда пересматривать план

| Периодичность | Что проверять |
| :--- | :--- |
| Каждый месяц | Актуален ли текущий этап? |
| Каждые 3 месяца | Актуальны ли инструменты и сертификаты? |
| Раз в год | Та ли цель? |

### Как выбрать инструмент (язык, фреймворк, библиотеку)

| № | Критерий |
| :--- | :--- |
| 1 | Используется в 10+ актуальных вакансиях по целевой роли. |
| 2 | Есть официальная документация и активное сообщество. |
| 3 | Дата последнего обновления — не старше 6 месяцев. |

### Как выбрать сертификат

| № | Критерий |
| :--- | :--- |
| 1 | Указывают в требованиях вакансий. |
| 2 | Срок действия — не меньше 2 лет. |
| 3 | Стоимость продления/пересдачи — приемлемая. |

### Что делать, если инструмент устарел

| № | Шаг |
| :--- | :--- |
| 1 | Не менять цель этапа. Менять только инструмент. |
| 2 | Найти актуальную замену по критериям выше. |
| 3 | Обновить план. Сделать коммит с понятным сообщением. |

### Что делать, если цель достигнута быстрее

| № | Шаг |
| :--- | :--- |
| 1 | Переходить к следующему этапу. |
| 2 | Не тратить время на «добивание» уже освоенного. |

### Кто отвечает за обновление

| Кто | Роль |
| :--- | :--- |
| Ты | Принимаешь решения. |
| Ментор (AI) | Проверяет актуальность, предлагает изменения. |
| Вместе | Обсуждаете и утверждаете. |

## Главное правило

Сертификат **не делает** тебя инженером. Он лишь **открывает дверь**. **Портфолио на GitHub** — это то, что **заставляет** работодателя **нанять** тебя.

**Формула:** Бесплатные курсы + Проекты + Платный сертификат (только на Этапе 4–5).
