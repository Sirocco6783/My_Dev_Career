# ГЕНЕРАЛЬНЫЙ ПЛАН

**Цель:** Стать специалистом в области **AI Enterprise Architecture**. Проектировать и внедрять корпоративные AI-решения. Работа удалённо.

**Принципы:**
1. 80% времени — практика (писать код руками).
2. Один основной ресурс за раз (Edube — фундамент).
3. Бесплатно — везде, где это возможно.
4. Платить — только за то, что даёт реальный вес в глазах работодателя.
5. Планы гибкие, корректируются по факту.

**Критерии выбора платных ресурсов:**
- Авторитет среди IT-компаний.
- Современность (актуальность в 2026 году).
- Окупаемость (цена соответствует отдаче).
- Практическая ценность (учит строить, а не просто знать).

---

## Этап 1. Фундамент (Python)

**Срок:** 3–4 месяца.
**Цель:** Свободно владеть Python. Понимать основы ООП. Работать с файлами и структурами данных.

**Ресурсы:**
- Python Essentials 1 (PE1) — Edube. **В процессе.**
- Python Essentials 2 (PE2) — Edube. **Следующий шаг.**

**Сертификат:** PCEP ($59) — по желанию. Не обязателен. Проекты важнее.

**Результат:** Можешь написать простое приложение (калькулятор, справочник, игру).

---

## Этап 2. Веб-разработка и API (Backend)

**Срок:** 2–3 месяца.
**Цель:** Строить REST API на FastAPI. Подключать внешние сервисы. Работать с базами данных.

**Ресурсы:**
- Официальная документация FastAPI.
- Плейлист «FastAPI Beyond CRUD» (Ssali Jonathan) — YouTube.
- DataCamp (бесплатный курс по FastAPI).

**Сертификат:** Не нужен. Проекты важнее.

**Результат:** Первые заказы на фрилансе ($10–50). API для заметок, Telegram-бот с базой данных.

---

## Этап 3. AI-интеграции

**Срок:** 3–4 месяца.
**Цель:** Подключать готовые AI-модели (API) к веб-приложениям и ботам.

**Ресурсы:**
- Документация Google Gemini, OpenRouter.
- YouTube (конкретные видео по aiogram, requests, asyncio).

**Сертификат:** Не нужен. Проекты важнее.

**Результат:** Ценник растёт ($50–150). Telegram-бот с AI (Gemini/OpenRouter).

---

## Этап 4. Облачные технологии и MLOps

**Срок:** 3–6 месяцев.
**Цель:** Разворачивать AI-приложения в облаках. Работать с Docker, CI/CD.

**Ресурсы:**
- Microsoft Azure AI Engineer Associate (AI-102) — **$165**. Весомый сертификат.
- AWS Certified AI Practitioner — **$100**. Базовый, полезен.
- Databricks Generative AI Engineer Associate — **headline-сертификат 2026 года**.

**Результат:** Middle-разработчик ($1000–3000).

---

## Этап 5. AI Enterprise Architecture

**Срок:** 1–2 года (после Этапа 4).
**Цель:** Проектировать корпоративные AI-решения.

**Ресурсы:**
- Google Professional Machine Learning Engineer (~$200).
- Microsoft Agentic AI Business Solutions Architect — новый expert-уровень.
- LangChain, Hugging Face, векторные базы данных.

**Результат:** Senior AI Architect. Доход $5000–10000+.

---

## Главное правило

Сертификат **не делает** тебя инженером. Он лишь **открывает дверь**. **Портфолио на GitHub** — это то, что **заставляет** работодателя **нанять** тебя.

**Формула:** Бесплатные курсы + Проекты + Платный сертификат (только на Этапе 4–5).
